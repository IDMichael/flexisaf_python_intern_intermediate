# Library Management System

## Overview

This Python program simulates a simple library management system using Object-Oriented Programming (OOP).

The program:
* Creates book objects with title, author, and availability status
* Allows books to be borrowed and returned
* Stores multiple books in a library collection
* Searches for books by title
* Searches for books by author
* Manages borrowing and returning operations
* Displays all books and their current availability status

## Features
* Book management using classes
* Borrow and return functionality
* Search books by title
* Search books by author
* Availability tracking
* Library collection management
* Clean and readable output

## Technologies Used
* Python 3
* Object-Oriented Programming (OOP)

## Required Libraries
No external libraries are required.
This program uses only Python built-in features.

## How to Run the Program
### 1. Navigate into the folder
cd library_management_system

### 2. Run the program
python library_management_system.py
