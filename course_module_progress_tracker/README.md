# Course Module Progress Tracker

## Overview

This Python program models a course module using Object-Oriented Programming (OOP) principles.

The program:
- Defines a `CourseModule` class
- Encapsulates module title, content, and completion status
- Validates user input during object creation
- Prevents direct modification of internal attributes
- Updates module progress through a public method
- Displays formatted module information

## Features
- Encapsulation
- Input validation
- Private attributes
- Public getter methods
- Progress update system
- Formatted string representation

## Technologies Used
- Python 3

## Required Libraries
No external libraries are required. This program uses only Python built-in features.

## How to Run the Program
### 1. Navigate into the folder

cd course_module_progress_tracker

### 2. Run the program
python course_module_progress_tracker.py
