# Student Score Report System

## Overview
This Python program calculates and reports student scores using advanced function parameters, argument unpacking, and variable scopes.

The program:
- Accepts multiple student scores using `*args`
- Accepts optional grading settings using `**kwargs`
- Applies score weighting and bonus marks
- Calculates total score and average score
- Determines the final grade
- Generates a formatted student performance report

## Features
- Flexible score input
- Tuple unpacking
- Dictionary unpacking
- Grade calculation system
- Input validation
- Clean report generation

## Technologies Used
- Python 3

## Required Libraries
No external libraries are required.
This program uses only Python built-in features.

## How to Run the Program

### 1. Navigate into the folder
cd student_score_calculation

### 2. Run the program
python student_score_calculation.py
