# Student CSV Cleaner

## Overview
This Python program reads a CSV file containing student names, scores, and departments, validates each record, and generates a cleaned CSV file containing only valid student records.

The program:
- Loads student records from a CSV file
- Validates each row
- Removes rows with missing or invalid data
- Trims unnecessary whitespace
- Converts valid scores into numeric values
- Writes the cleaned records to a new CSV file

## Features
- CSV file reading
- Row validation
- Missing data detection
- Score validation
- Automatic data cleaning
- Clean CSV file generation

## Technologies Used
- Python 3

## Required Libraries
No external libraries are required.
This program uses only Python built-in features.

## How to Run the Program
### 1. Navigate into the folder
cd student_csv_cleaner

### 2. Run the program
python student_csv_cleaner.py
