# Payroll Management System

## Overview
This Python program models an organization's payroll system using Object-Oriented Programming (OOP) principles.

The program:
* Defines an `Employee` base class
* Extends the base class into `Manager` and `Developer`
* Calculates employee bonuses using polymorphism
* Calculates each employee's total pay
* Supports multiple payment methods
* Processes payroll and generates a formatted payroll report

## Features
* Inheritance
* Polymorphism
* Composition
* Encapsulation
* Input validation
* Payroll report generation
* Multiple payment methods
* Employee registration system

## Technologies Used
* Python 3

## Required Libraries
No external libraries are required.
This program uses only Python built-in features.

## How to Run the Program
### 1. Navigate into the folder
cd payroll_management_system

### 2. Run the program
python payroll_management_system.py
