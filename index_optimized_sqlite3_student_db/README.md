# Student Database Management System

## Overview

This Python program manages student records using SQLite and demonstrates database optimization techniques.

The program:
- Stores student records in a SQLite database
- Performs Create, Read, Update, and Delete (CRUD) - operations
- Searches students by name
- Records database activities in a logs table
- Uses transactions to maintain data integrity
- Implements foreign keys for relational integrity
- Uses indexes to optimize query performance
- Displays SQLite query execution plans

## Features
- Student CRUD operations
- Student name search
- Activity logging
- SQLite transactions
- Foreign key relationships
- Database indexing
- Query optimization with EXPLAIN QUERY PLAN
- Input validation
- Menu-driven interface

## Technologies Used
- Python 3
- SQLite3

## Required Libraries
No external libraries are required.
This program uses only Python built-in libraries.

## How to Run the Program
### 1. Navigate into the folder
cd index_optimized_sqlite3_student_db

### 2. Run the program
python main.py
