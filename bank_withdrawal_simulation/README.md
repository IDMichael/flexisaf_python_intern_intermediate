# Bank Withdrawal System

## Overview

This Python program simulates a secure bank withdrawal system using object-oriented programming, exception handling, and transaction logging.

The program:

* Accepts withdrawal amounts from users
* Validates monetary inputs safely using `Decimal`
* Prevents invalid or negative transactions
* Raises custom exceptions for insufficient balance
* Logs all transactions with timestamps
* Uses `try`, `except`, `else`, and `finally` blocks properly

## Features

* Secure withdrawal system
* Accurate currency calculations using `Decimal`
* Custom exception handling
* Input validation
* Transaction logging with timestamps
* Deposit and withdrawal functionality
* Clean object-oriented structure
* Production-level error handling

## Technologies Used

* Python 3

## Required Libraries

No external libraries are required.
This program uses only Python built-in libraries:

* decimal
* datetime

## How to Run the Program

### 1. Navigate into the folder

cd bank_withdrawal_system

### 2. Run the program

python bank_withdrawal_system.py
